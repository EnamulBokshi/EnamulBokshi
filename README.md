### 🎬 AdCut — Prompt-Based AI Video Editor
> **Live:** [adcut-web-production.up.railway.app](https://adcut-web-production.up.railway.app/) · **Code:** [GitHub](https://github.com/EnamulBokshi/adcut)

An AI video editor where you edit by prompting, with no editing skills required.

**Highlights:**
- Cut render time by up to 89% (7–9× faster in 1080p–4K benchmarks) with raw RGBA piping, a worker-thread pool, and NVENC GPU detection with CPU fallback
- Unified multi-track timeline where manual and AI edits run through 26 Zod-validated operations, with version history and FCPXML/OTIO export
- Tech: `TypeScript` · `Next.js` · `Zod` · `FFmpeg` · `Skia` · `Worker Threads` · `Railway`
